# Greenwashing Flags You Can Understand — Not Just 'High Risk'

Canonical: https://senseible.earth/climate-intelligence/greenwashing-flags-explainable-not-just-high-risk

A greenwashing risk label that says "HIGH" without explanation is useless — and potentially damaging. Explainable Greenwashing Flags show exactly which variable triggered the assessment: "78% of values are round numbers — unusual for real-world data" or "3/5 records missing invoice documentation." Each factor is a specific, fixable data point, not a vague judgment. This transparency serves three purposes: it helps MSMEs fix genuine data issues, it prevents false positives from blocking legitimate claims, and it builds auditor confidence in the platform's integrity assessment. The algorithm checks four dimensions: data pattern analysis (round numbers, identical factors), documentation completeness (invoice numbers, vendor details), confidence distribution (average OCR quality), and factor diversity (same emission factor across all records). Each check produces a human-readable explanation. For a Rajkot brass manufacturer flagged as "MEDIUM risk" due to identical emission factors, the explanation revealed that all invoices were for the same fuel type — a legitimate scenario, not greenwashing. The manufacturer added a note explaining the pattern, and the next verification passed with "LOW risk." Explainable AI doesn't just detect problems — it enables solutions.
