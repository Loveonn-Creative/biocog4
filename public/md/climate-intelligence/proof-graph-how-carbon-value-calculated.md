# The Proof Graph: See Exactly How Your Carbon Value Is Calculated

Canonical: https://senseible.earth/climate-intelligence/proof-graph-how-carbon-value-calculated

Carbon credits built on black-box AI will not survive regulatory scrutiny. The Proof Graph makes every calculation visible: Invoice → Line Item → Emission Factor → Scope Classification → CO₂ Calculation → Credit Outcome. Each node in the chain is clickable, showing the exact source value and methodology applied. When a steel exporter in Jamshedpur processes a diesel invoice, the Proof Graph shows: "1,200 litres diesel × 2.68 kgCO₂/litre (BIOCOG_MVR_INDIA_v1.0) = 3,216 kg CO₂e → Scope 1 → 3.2 tCO₂e credit-eligible." No estimation, no approximation — pure deterministic math traceable to the source document. This matters because CBAM regulators and carbon credit buyers increasingly demand full provenance. The EU's verification framework requires "complete traceability from activity data to reported emissions." MSMEs using Proof Graphs can satisfy this requirement without hiring consultants. The visual chain also catches errors that spreadsheets miss: if an emission factor seems wrong, the user spots it immediately in the graph. In 2024, Indian MSMEs lost an estimated ₹340 crore in potential carbon revenue due to untraceable calculations. The Proof Graph eliminates this loss at the source.
